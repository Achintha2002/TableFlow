Architecture Note: All mutations enforce strict Row-Level Security (RLS) policies in PostgreSQL. Sensitive writes (order status, bill settlements, user roles, voucher grants) are routed through authenticated backend endpoints powered by the Supabase Service Role key to prevent client tampering.
